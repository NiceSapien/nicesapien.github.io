NiceSapien's self-made personal website.
I built this site cuz i got a bit bored of my old site (a fork of brittany chiang's site) and i thought i should create my own since im a web developer!

## AI Decleration
AI was used for some minor formatting and animation. The rest is designed and written by myself. Some of the project archive page was built by AI.

## Tech used
HTML, CSS and JavaScript.

Smooth delayed scrolling achieved using Lenis.

Hero text entry animation with animejs.

Built in pure b&w colors.
